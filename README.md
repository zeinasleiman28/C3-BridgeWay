# 🤝 Bridgeway – Agent-Powered Business Assistant

**EECE 503P – C3: Build an Agent-Powered Business Assistant**

**Rima** is the outreach advisor of *Bridgeway – Fundraising & Communications Consultancy for NGOs*, a fictional agency in Hamra, Beirut, that helps Lebanese NGOs reach donors, partners and volunteers.
Rima answers questions from the business documents, applies the discount rules, collects leads from interested NGOs, and records feedback and questions it can't answer.

It is built with the **`openai` Python SDK only** (no agent frameworks), works with **Google Gemini** (OpenAI-compatible endpoint) or **OpenAI**,
and has a **Gradio** chat interface.

## How it works

```
user message ──► ROUTER  classify_intent() → general_question / lead_collection / feedback
                    │    (LLM at temperature 0 returning JSON, keyword fallback)
                    ▼
             SYSTEM PROMPT = Persona + Instructions + Business Summary + Business PDF + route hint
                    │
                    ▼
             AGENT LOOP  ◄──►  TOOLS  record_customer_interest(email, name, message)
                    │                 record_feedback(question)
                    ▼
             REFLECTION  reviewer checks the draft against the instructions, revises if needed
                    │
                    ▼
                  reply
```

- **Persona** and **Instructions** are two separate, labeled blocks (notebook sections *🤝 Persona* and *📋 Instructions*).
- **Short-term memory:** the recent chat history (last ~20 turns) is sent with every message.
- **Tools** validate their input, print a log line and append a JSON line to `logs/`.
  Their schemas are documented MCP-style (`name`, `description`, `inputSchema`) and converted to the OpenAI `tools` format.
- **Robust:** a missing API key, network errors, rate limits and malformed model output produce clear messages, not crashes.

## Files

| File | What it is |
|---|---|
| `business_agent.ipynb` | **Main deliverable.** Builds the assistant step by step, readable top to bottom |
| `app.py` | The same assistant as a standalone app (local run + Hugging Face Space) |
| `me/business_summary.txt`, `me/about_business.pdf` | The business in two formats (the PDF is generated by `make_pdf.py`) |

| `llm.py` | Creates the LLM client from `.env` |
| `agent.py` | `run_agent()`: route → prompt → history → tool loop → reflection |
| `reflection.py` | The reflection reviewer (bonus) |
| `log_utils.py` | Shared JSONL logging helpers |
| `tests/` | Offline tests with a fake LLM (no API key needed) |

## Setup

Requires Python 3.10+. On Windows use `py`, on macOS/Linux use `python3`.

```bash
py -m venv venv
venv\Scripts\activate            # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env           # macOS/Linux: cp .env.example .env
```

Then open `.env` and add your key:

```ini
LLM_PROVIDER=gemini              # or: openai
GEMINI_API_KEY=...               # or OPENAI_API_KEY=... for openai
# LLM_MODEL=                     # optional: default gemini-3.5-flash-lite / gpt-4o-mini
# USE_REFLECTION=true            # optional: set to false to skip reflection
```

`.env` is gitignored. Never commit it.

## Run

| What | How |
|---|---|
| Notebook | Open `business_agent.ipynb` and run all cells. The last cell launches the chat |
| App | `py app.py`, then open http://127.0.0.1:7860 |
| Tests | `py -m pytest` |
| Rebuild the PDF | `py make_pdf.py` |

Messages to try:

| Message | Expected |
|---|---|
| "How much is a donor campaign for a small NGO?" | 600 minus 20% = **480 USD** |
| "I'm Maya from GreenSteps, maya@greensteps.org, we need volunteers in March" | `record_customer_interest` |
| "We need someone to write our EU grant proposal. Is that something you offer?" | Not offered → `record_feedback` |

While chatting, the console shows the agent's decisions:

```
[ROUTER] lead_collection (0.95, llm) - The user shares contact details and a need
📝 [LEAD] Maya <maya@greensteps.org>: GreenSteps – volunteer drive wanted for March
[TOOL] record_customer_interest(...) -> {'status': 'recorded', 'id': 'lead-3f9a1c2b'}
[REFLECTION] approved
```

Everything is also saved in `logs/` (committed on purpose, so the recorded leads and feedback are visible in the repo): `leads.jsonl`, `feedback.jsonl`, `router.jsonl`, `reflection.jsonl`.

## Deploy to Hugging Face Spaces (bonus)

1. Create a new Space at https://huggingface.co/new-space with **SDK: Gradio**.
2. In the Space's **Settings → Variables and secrets**, add the secret `GEMINI_API_KEY` (or `OPENAI_API_KEY`),
   plus `LLM_PROVIDER` if you use OpenAI.
3. Upload the project (the front matter at the top of this README configures the Space):

   ```bash
   pip install -U huggingface_hub
   hf auth login
   hf upload <your-username>/<space-name> . --repo-type space --exclude "venv/*" ".env" "logs/*.jsonl" ".git/*"
   ```

The Space installs `requirements.txt` and runs `app.py`.
